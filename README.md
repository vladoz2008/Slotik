# Slotik

Slotik - проект мобильной платформы для автоматизации записи к частным специалистам. Идея проекта: клиент видит свободные слоты и записывается без долгой переписки, а специалист управляет расписанием, подтверждениями и напоминаниями в одном месте.

## Текущий этап

Сейчас проект находится на этапе проверки проблемы и сбора первых ответов. Минимальная цель - собрать 15+ релевантных ответов, провести аналитику и на ее основе уточнить набор функций MVP.

## Как работать с задачами

Все задачи ведутся через GitHub Issues. Для каждой задачи лучше указывать цель, ссылки на материалы, критерии готовности и статус. Рекомендуемые статусы канбана:

1. `Backlog` - идея или задача на будущее.
2. `Ready` - задача понятна и готова к работе.
3. `In progress` - задача выполняется.
4. `Review` - результат нужно проверить.
5. `Done` - задача закрыта.

Подробная инструкция лежит в `docs/project_board.md`.
