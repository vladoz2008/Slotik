# Как провести аналитику после сбора ответов

Эта инструкция нужна после того, как Google Forms соберет минимум 15 ответов от целевой аудитории проекта «Слотик».

## 1. Проверить количество ответов

1. Откройте таблицу ответов: https://docs.google.com/spreadsheets/d/1KAKYqT0Ln9IZtZO9Ed7D0BlsJ2SC8SfH3L21F40rqxk/edit
2. Посчитайте строки с ответами. Первая строка — заголовки, поэтому для выполнения задания должно быть минимум 16 строк в таблице.
3. Убедитесь, что среди респондентов есть представители целевой аудитории: частные специалисты, клиенты частных специалистов или люди, которые относятся к обеим группам.

## 2. Скачать реальные результаты

В Google Sheets выберите:

`Файл -> Скачать -> Microsoft Excel (.xlsx)`

Дополнительно можно скачать CSV:

`Файл -> Скачать -> Значения, разделенные запятыми (.csv)`

Эти файлы и нужно сдавать как результаты реального анкетирования.

## 3. Создать Excel-файл с аналитикой

В итоговом Excel-файле сделайте отдельные листы:

1. `Исходные данные` — все ответы из Google Forms без изменений.
2. `Сводный анализ` — краткие таблицы по каждому вопросу.
3. `Проценты` — процентное распределение по закрытым вопросам.
4. `Открытые ответы` — группировка текстовых ответов по темам.
5. `Ключевые выводы` — подтверждение или опровержение гипотезы.
6. `Рекомендации` — что изменить или усилить в проекте.

## 4. Что посчитать

Для закрытых вопросов посчитайте количество и процент ответов:

- к какой группе относится респондент;
- как сейчас происходит запись;
- как часто приходится согласовывать время вручную;
- сколько времени занимает согласование;
- какие неудобства встречаются чаще всего;
- оценки 1-5 по свободным слотам;
- оценки 1-5 по напоминаниям;
- оценки 1-5 по интересу к записи в два клика.

Формула процента:

`Количество выбранного варианта / Общее количество ответов * 100`

Пример: если 11 из 15 человек выбрали «Долгое ожидание ответа», процент будет:

`11 / 15 * 100 = 73,3%`

## 5. Как считать вопросы с несколькими вариантами

В Google Forms ответы на checkbox-вопросы могут попадать в одну ячейку через запятую. Для таких вопросов удобно использовать `COUNTIF`.

Примеры формул:

```text
=COUNTIF(C:C;"*Через личные сообщения*")
=COUNTIF(F:F;"*Долгое ожидание ответа*")
=COUNTIF(F:F;"*Не видно свободные окна*")
```

Процент:

```text
=COUNTIF(F:F;"*Долгое ожидание ответа*") / COUNTA(A:A)
```

Если в столбце `A` есть заголовок, лучше считать только строки ответов, например `A2:A100`.

## 6. Как обработать открытые ответы

Открытые ответы не нужно просто копировать списком. Их нужно сгруппировать по повторяющимся темам.

Для вопроса «Что могло бы помешать пользоваться приложением?» возможные группы:

- нежелание устанавливать отдельное приложение;
- привычка записываться через Telegram;
- опасения по поводу персональных данных;
- страх, что специалист не будет обновлять расписание;
- цена или подписка.

Для вопроса «Какой функции не хватает?» возможные группы:

- видимые свободные слоты;
- напоминания;
- перенос или отмена записи;
- интеграция с календарем;
- связь с Telegram;
- повторная запись.

## 7. Какие выводы написать

В итоговых выводах ответьте на пять вопросов:

1. Подтвердилась ли гипотеза проблемы?
2. Какие трудности встречаются чаще всего?
3. Насколько аудитории интересен формат записи в два клика?
4. Какие функции оказались наиболее важными?
5. Что нужно изменить или усилить в проекте «Слотик»?

## 8. Готовый текстовый шаблон вывода

```text
По результатам анкетирования было собрано __ ответов. Большинство респондентов относится к целевой аудитории проекта: частным специалистам и клиентам частных специалистов.

Гипотеза проблемы подтвердилась / подтвердилась частично / не подтвердилась, потому что __% респондентов сталкиваются с ручным согласованием времени, а наиболее частыми трудностями стали: ______.

Наиболее востребованными функциями оказались: видимые свободные слоты, запись без переписки, автоматические напоминания и возможность переноса записи.

Интерес к решению можно оценить как высокий / средний / низкий: __% респондентов поставили оценку 4 или 5 по вопросу об интересе к приложению.

Для дальнейшей доработки проекта стоит усилить: ______.
```

## 9. Что сдавать после аналитики

После реального опроса нужно сдать:

- ссылку на Google Forms;
- ссылку на лендинг;
- файл CSV или Excel с реальными ответами;
- Excel-файл с аналитикой;
- краткий текстовый вывод по результатам.
