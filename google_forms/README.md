# Создание Google Forms для проекта «Слотик»

В этой папке лежит скрипт `create_slotik_form.gs`, который автоматически создает настоящую Google Form с вопросами анкеты и отдельную Google Sheets-таблицу для ответов.

## Как создать форму

1. Откройте [script.google.com](https://script.google.com/).
2. Нажмите **Новый проект**.
3. Удалите стандартный код и вставьте содержимое файла `create_slotik_form.gs`.
4. Сохраните проект, например с названием `Создание анкеты Слотик`.
5. В выпадающем списке функций выберите `createSlotikSurveyForm`.
6. Нажмите **Run / Выполнить**.
7. При первом запуске Google попросит авторизацию. Разрешите доступ к Forms и Sheets.
8. Откройте **Executions / Выполнения** или **Logs / Журнал** и скопируйте:
   - ссылку для респондентов;
   - ссылку для редактирования;
   - ссылку на таблицу ответов.

## Что делать после создания

1. Вставьте ссылку для респондентов в `index.html` вместо локальной `./survey.html`, если нужна именно внешняя Google Forms-ссылка на лендинге.
2. Разошлите форму минимум 15 представителям целевой аудитории.
3. После сбора ответов скачайте таблицу ответов в CSV или Excel.
4. Замените демонстрационный файл `data/slotik_survey_responses_demo.csv` реальными данными.
5. Пересоберите аналитику или используйте текущий Excel-файл как образец структуры.
